    How it works

    This page uses WebMCP, a draft web standard that lets a website hand an AI agent a list of actions it can take, so the agent doesn't have to guess what to click. The chat box above uses the same actions. Simple requests are understood by rules; free-form ones go to Chrome's built-in AI, which runs on your device. Nothing is stored on a server.
